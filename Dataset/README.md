# Dataset

This project uses data from the Surveillance, Epidemiology, and End Results (SEER) Program.

The study includes pancreas, stomach, and lung cancer cases diagnosed between 2004 and 2019.

Due to SEER data-use restrictions, the raw patient-level data are not included in this repository and cannot be redistributed.

Researchers interested in reproducing the experiments should obtain access to the SEER data directly through the official SEER Program and follow the preprocessing and cohort-selection procedures described in the associated manuscript.

This folder is retained only to document the dataset source and project structure.
